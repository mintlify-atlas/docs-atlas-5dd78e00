Promptlint is a static analyzer for the text you send to GPT-4, Claude, Gemini, and other large language models. Just as ESLint catches bugs and style problems in JavaScript before you ship, Promptlint catches security vulnerabilities, cost waste, quality issues, and structural gaps in your prompts before they ever reach the model. It runs entirely on your machine — no API calls, no data leaving your environment — and produces results in milliseconds.

## What Promptlint checks

Promptlint organizes its rules into four categories. Every finding carries one of three severity levels: `CRITICAL`, `WARN`, or `INFO`.

### Security

The most important category. Promptlint detects prompt injection attempts (including leetspeak and unicode-obfuscated variants), jailbreak patterns like "act as" or DAN prompts, hardcoded API keys and passwords, personally identifiable information (SSNs, credit cards, emails, phone numbers), and unsanitized user content injected into system prompts.

### Cost

Promptlint estimates the token count and per-call cost of every prompt based on your configured model and pricing. It also warns when a prompt exceeds your configured token budget, so expensive regressions get caught in CI before they reach production.

### Quality

Vague terms like "some", "stuff", and "maybe" are flagged. Passive voice, excessively long sentences, politeness filler ("please", "kindly", "thank you") that burns tokens without adding meaning, and redundant phrases ("in order to" → "to") are all detected. Many quality findings are auto-fixable with `--fix`.

### Completeness

Promptlint checks that your prompt has explicit sections for Task, Context, and Output; that a system role is defined; that an output format is specified; and that error-handling edge cases are addressed. It also flags prompts that ask the model to recall facts without any grounding context, reducing hallucination risk.

## Distribution channels

Promptlint is available wherever your workflow lives:

- **pip** — `pip install promptlint-cli` (Python 3.9+)
- **npm** — `npm install -g promptlint-cli` (Node.js 16+)
- **GitHub Action** — zero-install CI integration via `AryaanSheth/promptlint@v1`
- **VS Code** — inline diagnostics from the Marketplace extension (`PromptLint.promptlint-vscode`)
