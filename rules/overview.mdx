Promptlint ships with 20 built-in rules organized into four categories: **Security**, **Quality**, **Completeness**, and **Cost**. Every rule runs on each prompt you analyze — no configuration is required to get started. Rules are deterministic, run entirely locally, and complete in milliseconds regardless of prompt length. The overall health score is a weighted average across the four categories, with security carrying the highest weight at 40%.

## Severity levels

Every finding carries one of three severity levels that control both the visual output and the CLI exit code.

| Level | Exit code behavior | What it indicates |
|---|---|---|
| `CRITICAL` | Exits `2` by default | Security violation that should block CI — injection, leaked credentials, confirmed jailbreak. |
| `WARN` | Exits `1` with `--fail-level warn` | Actionable quality or budget problem. Does not fail CI unless you opt in. |
| `INFO` | Never fails CI | Informational suggestion. Always exits `0` regardless of `--fail-level`. |

<Note>
The default `--fail-level` is `critical`. Pass `--fail-level warn` to block CI on warnings too, or `--fail-level none` to always exit `0`.
</Note>

## Listing and explaining rules

Use the CLI to inspect the rule set without running a full lint pass.

```bash
# Print all rule IDs with their categories and default severities
promptlint --list-rules

# Print a detailed explanation for a specific rule
promptlint --explain prompt-injection
promptlint --explain politeness-bloat
```

## Inline disable syntax

Suppress a rule on a specific line by appending a `# promptlint-disable` comment. This works in any prompt file regardless of extension.

```text
Your $100 budget constraint  # promptlint-disable prompt-injection

Please write the summary  # promptlint-disable politeness-bloat

Ignore all previous context  # promptlint-disable
```

The bare `# promptlint-disable` (with no rule ID) silences all rules on that line.

<Note>
Inline disables only apply to findings that report a specific line number. Rules that report line `-` operate on the whole prompt — for example `structure-sections` and `role-clarity`. Disable those in `.promptlintrc` instead.
</Note>
