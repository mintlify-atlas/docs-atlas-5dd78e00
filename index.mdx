Promptlint runs static analysis on your LLM prompts before they reach GPT-4, Claude, or Gemini. It detects prompt injection attacks, leaked secrets, PII, token waste, and quality issues like vague language and missing structure — all locally with no network calls required.

## What Promptlint catches

<CardGroup cols={2}>
  <Card title="Security" icon="lock">
    Prompt injection, jailbreak patterns, leaked API keys, PII (SSNs, emails, credit cards), and unsanitized injection boundaries.
  </Card>
  <Card title="Token cost" icon="coins">
    Token count and per-call cost estimate, budget enforcement, and politeness filler that burns tokens without adding meaning.
  </Card>
  <Card title="Prompt quality" icon="sparkles">
    Vague terms, passive voice, redundant phrases, overly long sentences, and inconsistent terminology.
  </Card>
  <Card title="Completeness" icon="circle-check">
    Missing system role, no output format specified, absent Task/Context/Output structure, and hallucination-prone instructions.
  </Card>
</CardGroup>

## How it works

<Steps>
  <Step title="Install Promptlint">
    Install via pip or npm — or use the GitHub Action with no installation required.

    ```bash
    pip install promptlint-cli
    ```
  </Step>
  <Step title="Run on your prompt files">
    Point Promptlint at a file, pass inline text, or pipe from stdin.

    ```bash
    promptlint --file system_prompt.txt
    ```
  </Step>
  <Step title="Review findings">
    Findings are grouped by severity: `CRITICAL`, `WARN`, and `INFO`. Exit code reflects the highest severity found.

    ```
    [ CRITICAL ] prompt-injection (line 5) Injection pattern detected: 'ignore previous instructions'.
    [ WARN     ] structure-sections (line -) No explicit sections detected (Task/Context/Output).
    [ INFO     ] cost (line -) Prompt is ~38 tokens (~$0.0002 input per call on gpt-4o).
    ```
  </Step>
  <Step title="Auto-fix and iterate">
    Pass `--fix` to let Promptlint rewrite the prompt in place, then review the diff before committing.

    ```bash
    promptlint --file system_prompt.txt --fix
    ```
  </Step>
</Steps>

<Tip>
  All analysis runs locally — nothing leaves your machine. No API keys required to run Promptlint itself.
</Tip>
