Promptlint is available as a Python package and a Node.js package. Both expose the same `promptlint` command. Pick whichever runtime you already have, or see the [installation page](/installation) for the GitHub Action and VS Code options.

<Note>
  All analysis runs locally on your machine. No prompt text is sent to any external service or API.
</Note>

<Steps>

  <Step title="Install Promptlint">
    <CodeGroup>

    ```bash pip
    pip install promptlint-cli
    ```

    ```bash npm
    npm install -g promptlint-cli
    ```

    </CodeGroup>

    Verify the install:

    ```bash
    promptlint --version
    ```
  </Step>

  <Step title="Lint your first prompt">
    The fastest way to try Promptlint is with inline text using the `-t` flag. No files needed:

    ```bash
    promptlint -t "Please write some code for me"
    ```

    To lint a file on disk:

    ```bash
    promptlint --file system_prompt.txt
    ```

    You can also pass multiple files or glob patterns:

    ```bash
    promptlint prompts/**/*.txt --exclude prompts/drafts/*
    ```
  </Step>

  <Step title="Read the findings">
    Here is the output from scanning a prompt file that contains several issues:

    ```
    $ promptlint --file system_prompt.txt

    PromptLint Findings
    [ INFO     ] cost (line -) Prompt is ~38 tokens (~$0.0002 input per call on gpt-4o).
    [ WARN     ] structure-sections (line -) No explicit sections detected (Task/Context/Output).
    [ WARN     ] clarity-vague-terms (line 1) Vague term 'some' detected. Be more specific.
    [ INFO     ] verbosity-redundancy (line 3) Redundant phrase 'In order to' detected. Use simpler alternative.
    [ WARN     ] politeness-bloat (line 1) Consider removing 'Please' (adds 1.5 tokens without semantic value).
    [ CRITICAL ] prompt-injection (line 5) Injection pattern detected: 'ignore previous instructions'.

    1 file(s) scanned, 6 finding(s) in 0.41s
    ```

    Each finding shows the severity level, rule ID, line number, and a plain-English message. The severity levels are:

    - `CRITICAL` — security risks: injection, jailbreaks, leaked secrets, PII
    - `WARN` — quality and structural issues that affect model output
    - `INFO` — cost estimates and minor style suggestions

    **Exit codes** map directly to severity so you can use Promptlint in scripts and CI:

    | Exit code | Meaning |
    |-----------|---------|
    | `0` | Clean — no findings at or above the fail level |
    | `1` | Warnings found (requires `--fail-level warn`) |
    | `2` | Critical findings found |
  </Step>

  <Step title="Configure for your project">
    Generate a starter `.promptlintrc` configuration file in your current directory:

    ```bash
    promptlint --init
    ```

    This creates a `.promptlintrc` with all rules enabled and default settings for `gpt-4o`. Open it to tune your token budget, cost model, and individual rule settings:

    ```yaml
    model: gpt-4o
    token_limit: 800
    cost_per_1k_tokens: 0.005
    calls_per_day: 10000

    rules:
      prompt_injection:
        enabled: true
        patterns:
          - ignore previous instructions
          - system prompt extraction
      politeness_bloat:
        enabled: true
        words: [please, kindly, thank you, i would appreciate]
      role_clarity:
        enabled: true
        severity: warn   # downgrade from CRITICAL

    fix:
      enabled: true
      prompt_injection: true
      politeness_bloat: true
      verbosity_redundancy: true
      structure_scaffold: true
    ```

    Promptlint looks for `.promptlintrc` in the current working directory. Run from your repo root, or pass `--config path/to/.promptlintrc` explicitly.
  </Step>

</Steps>

## Common next steps

**Auto-fix what can be fixed automatically:**

```bash
promptlint --file prompt.txt --fix
```

The `--fix` flag rewrites the prompt in place and prints the optimized version:

```
$ promptlint -t "Please kindly write code in order to sort the array, thank you" --fix

Optimized Prompt
<task>Write code to sort the array.</task>
```

**Run in CI with a strict fail level:**

```bash
promptlint prompts/ --fail-level warn --quiet
```

**Output JSON for downstream tooling:**

```bash
promptlint --file prompt.txt --format json
```

**Explain a specific rule:**

```bash
promptlint --explain prompt-injection
```

**Suppress a rule on a specific line:**

```
Your $100 budget  # promptlint-disable prompt-injection
```
